# Referências locais

Esta pasta contém cópias dos materiais acadêmicos recebidos durante a organização inicial.

Antes de publicar o repositório:

1. confirmar autoria e permissão de redistribuição de cada arquivo;
2. manter o manual institucional identificado por instituição, versão e data;
3. substituir arquivos de terceiros por links oficiais quando a redistribuição não estiver autorizada;
4. registrar as referências bibliográficas no formato adotado no TCC.

Os arquivos desta pasta não são dependências para executar o controlador ou as topologias.
