# Referências locais

Esta pasta contém cópias de materiais acadêmicos recebidos durante o desenvolvimento.

Antes de tornar o repositório público:

1. confirme autoria e permissão de redistribuição de cada arquivo;
2. mantenha o manual institucional identificado por instituição, versão e data;
3. substitua arquivos de terceiros por links oficiais quando a redistribuição não estiver autorizada;
4. registre as referências bibliográficas no formato adotado pelo TCC.

Esses arquivos não são necessários para executar o controlador ou as topologias.
